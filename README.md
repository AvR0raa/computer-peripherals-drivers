## 这是什么

Windows 上的**通用外设调试器**：

- 🔋 **电量一目了然** —— 打开软件自动扫描全部设备电量，托盘常驻
- 🖱️ **鼠标直接调** —— DPI（带档位表）、报告率（125–8000Hz），读回验证防写坏
- 🔍 **插入即识别** —— 30+ 品牌 VID 库，自动识别品牌/型号/类型，过滤系统内部设备
- 🧪 **学习模式** —— 遇到没适配的设备？录一次官方驱动的对话，自动逆向出协议
- 📦 **免安装** —— 双击 exe 即用，无需 Python、无需任何厂商驱动

## 命令行（可选）

```bat
python cli.py list          :: 设备清单 + 识别状态
python cli.py battery       :: 全设备电量
python cli.py mouse         :: 罗技鼠标完整报告（唤醒/DPI/电量）
python cli.py mouse --set 1600 --rate 2000   :: 设置 DPI 和报告率
python gui.py               :: 图形界面
```

## 它是怎么工作的（给开发者）

- 罗技：HID++ 2.0 协议（短/长报文双通道，字节级对齐 Solaar）
- 国产品牌电量：[EZ2.4G](https://github.com/Ap0LoG1zE/EZ2.4G) 移植（ATK / MCHOSE / 杰理 TLV）
- 其他：标准 HID Battery System 页 + 厂商自定义接口只读探测
- 所有写操作走 `读旧值 → 写新值 → 读回验证 → 失败回滚` 安全路径
- 逐字节的协议文档见 [protocol_db/brands/](protocol_db/brands/)（一品牌一文件）

## FAQ

**Q: 为什么我的鼠标电量显示"睡眠中"？**
无线鼠标省电睡眠时不响应查询——动一动鼠标再点「读取全部电量」。

**Q: DPI 设置了但没生效？**
罗技鼠标开着「板载配置档」时主机写入可能不生效——在 G HUB 里把 Onboard Profiles 切到 Disable（Host 模式）。

**Q: 会写坏我的设备吗？**
所有写操作都有读回验证，验证失败会自动把旧值写回去；学习模式只读录制，零写入。

**Q: 杀毒软件报毒？**
PyInstaller 打包的常见误报，加入白名单即可（源码全开源，可自行编译）。

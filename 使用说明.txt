外设万能调试器PeripheralTool — 使用说明
=============================================

一个软件总览并调节所有外设：设备识别 / 电量 / 罗技鼠标 DPI / 学习模式逆向。

【启动】
    双击 PeripheralTool.exe 即可（无需安装 Python）。
    首次启动可能被 Windows Defender SmartScreen 提示，点「更多信息」→「仍要运行」。

【三个标签页】

  1. 总览
     - 全部设备一张卡片墙，插拔实时更新
     - 「读取全部电量」：一键扫所有设备电量
       · 罗技设备自动走 HID++（接收器逐槽位）
       · 其他设备扫标准 HID 电量页
       · 都没有的会提示"需学习模式"

  2. 设备
     - 左侧设备列表（绿=已识别 / 蓝=有官方SDK / 灰=未知）
     - 右侧详情：接口表、描述符解析、协议功能按钮
     - 罗技接收器会自动出现「鼠标 DPI」面板：
       读取当前 DPI / 档位表 → 拖滑条 → 应用（带读回验证+失败自动回滚）
       ※ 鼠标睡眠时请动一动鼠标；板载配置档开启时写入可能不生效
         （需在 G HUB 把 Onboard Profiles 切到 Disable/Host 模式）
     - 「批量探测」按钮：一键扫全部已知品牌设备
     - 配置档案：保存/加载/一键应用当前参数

  3. 学习模式（逆向未知设备）
     ① 勾选要录制的接口（vendor/rawhid）
     ② 开始录制 → 标记起点
     ③ 去该品牌的官方驱动软件改一次设置（如改 DPI/灯效）
     ④ 回来点「停止并分析」→ 差分结果自动列出变化字节
     ⑤ 填写说明 → 「生成草稿入库」→ 设备页立刻出现新功能按钮

【命令行】（可选，在本目录执行）
    PeripheralTool.exe 只是 GUI；命令行功能需要 Python 环境：
    python cli.py list         设备清单
    python cli.py battery      全设备电量
    python cli.py mouse        罗技鼠标完整报告（唤醒/DPI/电量）
    python cli.py mouse --set 1600   设置 DPI
    python cli.py watch        热插拔监视

【安全说明】
    - 所有写操作（DPI/协议功能）都带"读旧→写→读回验证→失败自动回滚"
    - 学习模式只读录制，绝不写入
    - 全程 TX/RX hex 日志可在界面底部查看

【常见问题】
    Q: 罗技鼠标显示"不在线"？
    A: 鼠标省电睡眠中，动一动鼠标即可（软件会自动重试唤醒）。
    Q: 电量显示"需学习模式"？
    A: 该品牌电量协议未公开，用学习模式抓一次官方软件即可入库。
    Q: 杀毒软件报毒？
    A: PyInstaller 打包的常见误报，加入白名单即可。
